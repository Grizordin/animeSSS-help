# Лимиты обменов в помощнике

Настройки: **Карты → Лимиты обменов → Показывать числа**. Оба переключателя по умолчанию выключены; при включении модуля используются точки. Числовой режим показывает свободные места (`0/3`–`3/3`). Предпочтения сохраняются стандартным механизмом помощника, отдельно по каждому полю, и синхронизируются между вкладками.

Интегрированный модуль не выводит отдельную панель, журнал, кнопку экспорта или импорта. Это пассивный трекер исходящих предложений; отправка, принятие и отмена обменов не автоматизируются.

## Переход с прототипа

- Выключить отдельный `AnimeSSS_trade_limits.user.js` в Tampermonkey, обновить открытые вкладки, включить модуль в помощнике.
- Хранилища разных userscript изолированы. По решению пользователя импорт не предусмотрен. Старые данные отдельного скрипта не удаляются, но помощник их не читает.
- У помощника собственная история `suite_trade_limits_v1:state:<ник>`. Обмены, завершённые до начала наблюдения помощником, автоматически не восстанавливаются. Посещение «Отправленные» позволяет учесть показанные сегодняшние предложения; без наблюдения отправки у них может не быть ID получаемой карты, поэтому подтверждение по истории может остаться неопределённым.
- При обнаружении перехватчиков старого отдельного скрипта модуль помощника не запускается и записывает `standalone_conflict` в общие логи. Это предотвращает второй собственный обход; после отключения старого скрипта требуется обновление страницы.

## Отображение и очередь

Поддержаны оба домена: `animesss.tv` и `animesss.com`. Проверки выполняются только на текущем домене. Плитки отображаются у всех обладателей, готовых обменять, на страницах звёзд 1–5 и пробуждения. Пьедесталы не затрагиваются. В пробуждении сохраняется собственная заливка сайта. Усиленная обводка онлайна, ЧС и запреты не заменяются индикаторами лимита.

Все запросы трекера — GET. Общий бюджет: максимум 90 запросов за скользящую минуту, минимум 700 мс между запросами, минимум 60 секунд между проверками одного ника. Фоновую работу выполняет только видимая вкладка с фокусом; очередь сохраняется при переходах. Без новых отправок принятые 1–2 обмена не опрашиваются; подтверждённый лимит не проверяется до следующих суток.

Состояние, очередь и бюджет общие через GM-хранилище. Для двух доменов используется координация претендентов по номеру очереди, а не только origin-local Web Locks. Владение продлевается раз в 2 секунды, истекает через 15 секунд без продления; перед запросами и сохранением проверяется владение. Ожидающий ответ не даёт новому обработчику начать параллельный обход. Потерявшая владение вкладка не сохраняет устаревший результат и не удаляет необработанные события.

## Общие логи

Модуль `trade_limits` использует существующую очередь `suiteTelemetryLog`, без отдельного сервера и без изменений Worker:

- ошибки сети, разметки, хранения, подключения обработчиков;
- неразрешённые проверки, неоднозначность и расхождение времени, корректировка по интервалу запроса, отсутствие серверной даты;
- ограничение повторов одного кода/пользователя/причины: 15 минут, максимум 80 разных таких записей за окно;
- обычные успешные проверки, клики и паузы из-за смены вкладки не отправляются;
- `daily_summary`: одна компактная сводка завершившихся суток по МСК — учтённые записи, принятые/отклонённые/ожидающие, подтверждённые лимиты, проверки, ошибки, запросы, исправления времени. Без списка ников и истории сделок. Формируется на смене суток или следующем запуске активного модуля. Если скрипт выключен/браузер закрыт, точная отправка в полночь не обещается.

Дополнительных запросов к сайту ради статистики нет. Штатная очередь телеметрии доставляет события своим обычным порядком. Не сохраняются cookie, user_hash, полные тела запросов или HTML-ответы.

## Исходники и проверки

Пользователь устанавливает только `AnimeSSS_help.user.js`; внешние `@require` не нужны. Блок в нём механически собирается из трекера и `tools/trade-limits-host.js`:

```text
node tools/embed-trade-limits.cjs
node tools/embed-trade-limits.cjs --check
node tests/trade-limits.cjs --without-exports
node tests/trade-limits-integration.cjs
node tests/settings-defaults.cjs
node tests/settings-persistence.cjs
```

Браузерные тесты используют headless Edge и подменяют всю сеть и GM-хранилище. По умолчанию HTML берётся из синтетических примеров `tests/fixtures/release-ui.cjs`; личные вложения и выгрузки не входят в репозиторий. `--without-exports` пропускает дополнительные проверки старых диагностических выгрузок. При необходимости сохранённые HTML можно проверить через `ANIMESSS_ATTACHMENTS` (корень локальных вложений).

Интеграционный сценарий запускает полный помощник на двух тестовых origin и проверяет меню, настройки, передачу очереди, выключение во время запроса, ограничения визуализации, обработчики и телеметрию. Это не подтверждение живой сессии Chrome + Tampermonkey; её проверяем после установки по общим логам.
